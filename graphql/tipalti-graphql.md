# Tipalti GraphQL API

Tipalti is a global payables automation platform covering supplier payments, invoice management, tax compliance, and global payment routing across 196 countries with 120+ currencies. The API covers payees, invoices, payment orders, and tax forms.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Tipalti REST API
**Documentation:** https://developer.tipalti.com/

- Reference: https://developer.tipalti.com/reference
- Schema: https://github.com/api-evangelist/tipalti
